# Devil's Advocate

Challenge the current decision, code change, or analysis. Find flaws before they ship.

## Instructions

1. **Identify the target**: If arguments provided, analyze that. Otherwise, analyze the most recent decision/change in conversation.

2. **Deep analysis** (think hard):
   - What assumptions are we making?
   - What's the failure mode nobody mentioned?
   - What evidence contradicts the conclusion?
   - What's the simplest thing that would make this wrong?
   - Who loses if we're wrong? How badly?

3. **Self-review for blind spots**:
   - Am I anchoring on the first solution?
   - Is there a simpler explanation I'm ignoring?
   - Would I bet money on this? How much?

4. **Challenge each point**:
   - For every claim: "What would have to be true for this to be wrong?"
   - For every benefit: "What's the hidden cost?"
   - For every assumption: "Says who? When was this last verified?"

5. **Synthesize**:
   - List confirmed flaws (with evidence)
   - List plausible risks (with likelihood estimate)
   - State what would change your mind
   - Final verdict: proceed / pause / rethink

## Rules

- Be genuinely adversarial — not performatively contrarian
- Attack the strongest point, not the weakest (steelman, then break it)
- If you can't find real flaws, say so — forced devil's advocacy is worse than none
- Keep it under 500 words unless the topic is genuinely complex
