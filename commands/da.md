# Devil's Advocate

Challenge the current topic, decision, or code change using the devil's advocate process from CLAUDE.md.

1. Claude: deep analysis with max reasoning, then self-review for blind spots
2. Gemini: challenge with `gemini -m gemini-3.1-pro-preview -p "Devil's advocate — find flaws, blind spots, wrong assumptions: <analysis>"`
3. Claude: synthesize Gemini's challenges, produce final result
4. If not confident, repeat 2-3

If arguments provided, analyze that topic. Otherwise analyze the most recent topic in conversation.
